# 하루섬 — 나만의 섬에서 보내는 하루

브라우저에서 바로 하는 섬 생활 게임. 섬은 매번 새로 생성되고, 동물 이웃들은 각자의 하루를 살고,
친구는 코드 하나로 내 섬에 놀러 온다(P2P). 그림·모델·얼굴·아이콘·음악은 전부 코드로 만들었다.

**플레이:** https://hwkim3330.github.io/haru-isle/

## 할 수 있는 것

- **생성되는 섬:** 해안선·모래사장·바위 해안, 3단 고지(둥근 절벽), 최고 고지에서 시작해 폭포로 떨어지며
  두 갈래로 바다에 닿는 강, 연못, 모든 땅이 걸어서 이어지도록 자동으로 놓이는 비탈과 다리. 처음엔 네 섬 중 하나를 고른다.
- **시간과 계절:** 실제 시계를 따라 흐르는 하루(아침·노을·밤하늘), 계절마다 바뀌는 풀빛과 잎, 겨울 눈,
  섬마다 같은 날씨(맑음·흐림·비·폭풍·눈). 매일 아침 과일이 다시 열리고 조개와 화석이 새로 묻힌다.
- **도구 8가지:** 삽(구멍·화석·바위·나무 옮겨 심기), 도끼(목재 3종), 잠자리채, 낚싯대(그림자 크기·입질·챔질),
  물뿌리개(꽃 교배로 새 색), 새총(풍선 선물), 사다리(절벽 오르기), 장대(강 건너뛰기). 도구는 닳는다.
- **도감:** 물고기 44종·곤충 46종이 장소·달·시간·날씨별로. 화석 24종. 박물관에 기증하면 수조와 진열장이 찬다.
- **이웃:** 16종 동물 × 8가지 성격에서 이름·말버릇·색·눈·옷·취미·생일이 생성된다. 각자 일어나고 자고,
  길을 찾아 걸어 다니며 노래하고 책 읽고 운동하고 낚시하고 서로 수다를 떤다. 대화·선물·부탁·우정,
  캠핑장 손님을 초대하면 이사 온다.
- **살림:** 잡화점(날마다 바뀌는 가구·옷·벽지, 매입, 주머니 확장, 일요일의 무 시세), 섬 사무소(공작대 제작, 저금),
  집(가구 배치·회전, 벽지·바닥, 보관함), 섬 디자인(흙·돌·벽돌·나무 길), 가구 약 60종 × 색 변형, 옷·모자.
- **친구와 함께:** 섬폰 → 친구 초대로 코드를 받아 알려 주면 최대 8명이 한 섬에서 논다. 섬 주인 브라우저가
  섬을 관리하고(땅 파기·줍기·흔들기 모두 동기화), 이웃·날씨·시간도 같다. 서버 없이 WebRTC(PeerJS).

## 조작

| | |
|---|---|
| WASD · 방향키 | 걷기 (Shift 달리기) |

터치 화면에서는 가상 스틱과 버튼이 나온다. 테스트용 주소: `?quick&seed=7&t=2026-04-05T14:30&wx=rain`.

## 어떻게 만들었나

Three.js + TypeScript + Vite. 섬 생성기(`src/world/island.ts`)가 격자를 만들고, 부호거리장을 흐려 둥근 절벽이 나오는
높이장(`terrain.ts`)으로 굽는다. 모든 재질은 셰이더 조각에서 "굴러가는 통나무"처럼 멀리 갈수록 휘어지고,
화면 위아래는 틸트시프트로 흐려진다. 캐릭터는 원시 도형 리그 + 캔버스에 그린 얼굴(눈 깜빡임·말할 때 입),
음악은 시간마다 씨앗으로 만든 화성·멜로디를 WebAudio로 합성한다.

```bash
pnpm install && pnpm dev            # http://localhost:5471
npx tsx tools/map.ts out.png 1 2 3  # 섬 생성기 결과를 지도로
node tools/flow.mjs                 # 흔들기·파기·가게·박물관·사무소·집 흐름
node tools/critters.mjs             # 낚시·곤충 채집
node tools/online.mjs               # 브라우저 둘로 P2P 방문
```
